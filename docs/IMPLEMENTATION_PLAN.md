# Implementation Plan: Prompt Paws — The Cozy AI Agent Cafe & Bakery

## 1. Vision & Differentiation
Instead of a dark cybernetic cloud-server tower-defense game, **Prompt Paws** teaches **Modern AI Agent Architecture** (LLM Routing, Context Caching, Input Guardrails, RAG Grounding, Deterministic Tool Calling, System-2 Extended Thinking, and Multi-Agent Orchestration) through a warm, pastel kawaii **2D Pastry Kitchen Simulation Game**.

## 2. Core Gameplay Loop
1. **Incoming Critter Orders**: Woodland critters place AI pastry orders along a winding pastel conveyor ribbon:
   - `🥐 Prompt Croissant` — Standard fast LLM generation
   - `🍪 Repeat Menu Query` — Ideal for Context Caching
   - `🌶️ Spicy Injection Jalapeño` — Adversarial prompt injection that must be sanitized first
   - `🍓 RAG Berry Tart` — Requires factual grounding from the Vector Berry Patch
   - `🧋 Code-Exec Boba` — Requires deterministic Tool Calling
   - `🍮 Deep-Think Soufflé` — Requires System-2 Reasoning
2. **Counter Placement & Upgrades**: Players spend `🪙 Star Coins` across 8 counter slots, upgrading stations from Lv.1 to Lv.3 or using the **✨ Auto-Chef Blueprint** button to deploy a reference architecture.
3. **Live Architecture Linter**: **Chef Whiskers** inspects placed stations against each shift's order distribution and provides real-time architectural hints.

## 3. Technical Stack
- **Rendering**: 60 FPS HTML5 2D Canvas (`game.js`) with custom vector Robot-Cat Chef sprites, animated ears, progress bars, and particle bursts.
- **Audio**: Zero-dependency WebAudio procedural synthesizer (`audio.js`).
- **Curriculum**: 7 progressive story shifts (`levels.js`) with post-shift AI engineering takeaways.
