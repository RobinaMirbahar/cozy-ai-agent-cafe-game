# Walkthrough: Prompt Paws — The Cozy AI Agent Cafe & Bakery

## 1. Overview
**Prompt Paws** is a 60 FPS playable educational web game that turns production AI Agent design patterns into an intuitive, cozy pastry kitchen experience.

![Prompt Paws Banner](../assets/cozy_ai_cafe_banner.jpg)

## 2. How Each Level Teaches an AI System Design Pattern
- **Shift 1 (Fast LLM Routing)**: Demonstrates how lightweight models (`🥐 Flash Pastry Oven`) handle high-volume everyday requests with low latency.
- **Shift 2 (Context Caching)**: Shows how caching repeated prefixes (`🍪 Context Cache Jar`) slashes latency and saves up to 95% of token costs.
- **Shift 3 (Input Guardrails)**: Introduces adversarial `🌶️ Spicy Prompt-Injection Jalapeños` that will ruin an unprotected pipeline unless sanitized at the entry by a `🛡️ Guardrail Flour Sieve`.
- **Shift 4 (RAG & Grounding)**: Shows why factual queries (`🍓 RAG Berry Tarts`) require a `🍓 Vector Berry Patch` so they don't reach the customer as `👻 Hallucination Puffs`.
- **Shift 5 (Deterministic Tool Calling)**: Introduces `🧋 Tool-Call Boba Mixers` for math and live API execution.
- **Shift 6 (System-2 Reasoning)**: Adds `🍮 Deep-Think Soufflé Ovens` for complex multi-step tasks.
- **Shift 7 (Multi-Agent Orchestration)**: Uses `🐱 Subagent Sous-Chef Bells` to speed up adjacent specialist stations in parallel.
